# TownLoop

TownLoop is an accessible resident living and engagement platform for active senior communities, featuring daily activities, dining menus, announcements, and direct community connectivity.

## Overview

TownLoop provides a comprehensive multi-community architecture designed specifically for senior living communities. Residents can access community calendars, RSVP to events, submit and track facilities maintenance work orders, interact via community discussions and marketplace, and stay informed with published community bulletins and newsletters.

## Architecture & Tenancy

- **TownLoop Core**: The overarching platform engine and user interface design system.
- **Community Tenancy**: Multi-tenant community support allowing users to choose their community campus (e.g., Cecil Pines Adult Living Community) or preview sandbox environments upon signing in.
- **Tech Stack**: React 19, TypeScript, Tailwind CSS, Vite, Express, and Firebase / Firestore.

## Features

- **Daily Living & Check-Ins**: Interactive daily checklists, medication reminders, and daily schedules.
- **Live Localized Weather**: Multi-day outlook and hourly forecasts tailored for the selected community campus.
- **Community Bulletin & Newsletters**: High-resolution canvas viewer for monthly community newsletters with AI-assisted event extraction.
- **Maintenance Work Orders**: Direct submission, status tracking, emergency contact info, and facilities routing.
- **Social Board & Marketplace**: Community discussion board, neighbor-to-neighbor listings, and direct contact options.
- **Accessible UI**: High-contrast typography, large touch targets, senior-friendly layouts, and light/dark theme toggle.
