# Dotrice Bold

Unmodified Dotrice Bold 1.001 by Paul Flo Williams, distributed under the bundled SIL Open Font License.
Source: https://www.1001fonts.com/dotrice-font.html
Archive: https://www.1001fonts.com/download/dotrice.zip

The original TownLoop CSS requests “Dotrice Bold”. The previous native TicketDotrice alias loaded DotGothic16 instead. This asset provides the actual bold face. All glyph advance widths are 720 units with 1000 units per em; Ticket uses these metrics to fit the code inside the SVG body.
